## 适用边界

本轮消除的是“没有检查实际输入”的不确定性，**不是证明重新提炼后仍会生成同一份 L3**。后续应复用本轮冻结 Memory；若重新提炼、采用其他底稿或改变注入配置，需要重新核对这些上下文相关标签。

目前 `reuse_preparation` 同时读取旧准备目录中的任务标签；不能误以为只设置这个选项就会自动采用本次修正标签。复跑时应保持同一份 Memory 底稿，并另行对齐最新标签。本次未改历史准备文件，也未扩展这一流程。

这次没有验收 Coding 完成、每次检索结果的完整性或所有后端工具业务。审核材料与 `reason` 仍不进入执行 Query 或任务工作区。
