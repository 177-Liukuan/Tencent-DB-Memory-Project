## 分组规则

`metrics/task-group.ts` 是评分、抽样、Viewer 和审核预览的共同入口。

- `should_call=false`：None。
- 正样本按 `allowed_first_tools` 的工具归属划分：只有 Memory、只有 Skill、两类都有（Mixed）。
- 已有序列规则取每条允许序列的首项，不把后续工具当作首次入口；缺少首次规则时使用现有 `expected_tools`。加载器继续负责旧字段的规范化。
- Knowledge、未知工具、空的正样本入口不能被猜成 Memory，明确报错；主评测原有工具范围检查保留。
- 不读取 ID 前缀、实际调用或 `tool_family` 来决定分组。后者仍是原有主要需求元数据，不增加第二套人工标签。

Mixed 的正确、选错和漏调用只进入 Mixed；总体每个样本只计一次。首次调用任一允许工具即可选对，不要求两类都调用，也不因后续改正而补分。

`by_task_group` 固定返回四组，字段为 `valid_samples`、`positive_samples`、`called_positive_samples`、`correct_tool_samples`、`negative_samples`、`false_call_samples` 和三项调用率。无效观测先剔除，不适用或分母为零的率为 `null`。Viewer 用“—”表示，不显示成 0%。

`by_tool_family` 的纯 Memory、Skill 正样本排除 Mixed；两类工具误调用率仍以全部有效 None 为分母。一个 None 同时调用两类工具，各自误调用计一次，总体误调用也只计一次。没有“Mixed 工具误调用率”。
