这些数据如何理解？

调用记录来自 Memory / Skill Bridge 入口，表示请求已到达 Bridge，不代表后端执行成功。展示顺序为 Bridge 接收顺序；并发时不一定等于模型生成顺序。

“符合预期”只评价是否调用及工具选择，不评价答案质量。采集异常不进入调用指标或延迟统计。分母为零的指标显示“—”，不是 0%。

端到端延迟从 Claude Code 启动提交输入起，到成功返回最终回答为止。对比只使用同一案例、同一重复编号的有效配对；先对每个案例的重复运行取均值，再汇总。Memory / Skill 的误调用率均以全部负样本为分母。

本观测格式不采集工具参数、业务返回值或静态注入 Token，因此不在此展示这些指标。
