这些数据如何理解？

调用记录来自 Memory / Skill Bridge 入口，表示请求已到达 Bridge，不代表后端执行成功。展示顺序为 Bridge 接收顺序；并发时不一定等于模型生成顺序。

“符合预期”只评价是否调用及工具选择，不评价答案质量。主指标只比较双方观测均有效、输入与标签一致的任务；任意一边观测无效，整对排除。有效无调用、已记录工具后停止均保留。分母为零显示“—”，不是 0%。

工具选择正确率 = 首次选对的正样本 / 本组已调用的正样本。因此即使使用同一批任务，两组分母也可能不同，应结合有效调用率理解。Memory／Skill 双入口单独统计，不进入纯 Memory 或 Skill 正样本组。

端到端延迟从 Claude Code 启动提交输入起，到成功返回最终回答为止。对比只使用同一任务、同一重复编号的有效配对；先对每个任务的重复运行取均值，再汇总。Memory / Skill 的误调用率均以全部负样本为分母。

本观测格式不采集工具参数、业务返回值或静态注入 Token，因此不在此展示这些指标。
