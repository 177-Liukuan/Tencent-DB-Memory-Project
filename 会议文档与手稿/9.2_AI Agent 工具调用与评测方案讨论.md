它该调用 Memory 工具的时候，会不会调用 Memory 工具，而且调用的是不是正确的；

在 Memory 场景里面，会不会错误调用 Skill；

在 Skill 场景里面，会不会错误调用 Memory。

这样就可以了。

另外你还要设置一定的**干扰项和负样本**。

比如说是一个纯写代码的任务，而你当前注入的资产全部都是运维相关的，那这些资产对当前任务没有任何帮助，这个时候模型就没必要去调用工具。

又比如就是一个纯写代码的情况，直接写代码就可以了，不需要调用任何资产工具。

这种误调用的情况你也要考虑进去。

所以你要把这几类情况都覆盖到你的评测集里面。

至于最原始的那些数据到底是你自己生成的，还是从哪里找来的，或者直接让 AI 写，其实都无所谓。
