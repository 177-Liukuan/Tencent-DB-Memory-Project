# 进展梳理



对TencentDB Agent Memory的理解：

从最直接的视角来看，任务一所处的系统会涉及到三个实体：LLM、Coding Agent客户端以及Tencent DB Agent Memory 。但从LLM侧来看，coding agent客户端+Tencent DB Agent Memory 都属于一个Agent系统中的Harness部分，为LLM提供对所处环境的观测和执行能力，并维护整个系统的运行时状态。Agent运行时状态中的一个关键模块就是Memory，它用来保存一些跨会话的长期记忆，比如说个人的习惯与偏好、团队的规范和约定等。一个好的Memory模块，或者说系统，需要组织好会话记忆的提炼保存，以及在适当的时机注入这些长期记忆。以claude code为例，目前市场上多数Agent 客户端都会有Memory功能，但这个功能往往是针对个人用户，且对用户来说，没有一个友好的可交互的管理控制台。于是，Tencent DB Agent Memory 应运而生，它以MemoryCore进行skill和meory的提炼，以Memoryknowledge提供知识管理服务，以MemoryPanel提供可视化的操作台，以MemoryProxy提提供跨平台扩展Memory接入以及团队Memory共享与分发。
